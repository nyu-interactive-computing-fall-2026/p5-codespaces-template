# p5.js Starter

A minimal p5.js sketch for experimenting in GitHub Codespaces. The p5.js library is loaded from jsDelivr, so the Codespace needs internet access when the page is first opened.

## Make a Copy of the Repository

1. Click the green Use this template button and select Create a new repository.
2. Set Owner to our Class Organization (do NOT choose your personal account).
3. Name you repository `assignment-1-yourgithubusername`.
4. Make sure the repository is set to Private.
5. Click Create repository from template.

## Open in Codespaces

1. In your **new** repository, click the green <> Code button.
2. Click the Codespaces tab.
3. Click Create codespace on main.
4. Allow 30–60 seconds for your cloud development environment to load in your browser.


## Saving Your Work
Run these three commands in your Codespace terminal whenever you want to save and submit your progress:

### Stage your changes:
Prepares all new and modified files for saving

```
git add .
```

### Commit your changes:
Saves a snapshot of your staged files with a short description

```
git commit -m "Complete exercise 1"
```

### Push to GitHub
Uploads your commits to your private GitHub repository.

```
git push
```


## If the embedded preview is blank

Live Preview currently documents a one-time Codespaces redirect workaround:

1. Open the **Ports** panel in the bottom panel.
2. Open the local address for port 3000, and port 3001 if it is listed, in a browser tab.
3. Wait for each page to finish redirecting, then close those tabs.
4. Reopen the Live Preview window.

If needed, use **Live Preview: Show Preview (External Browser)** from the Command Palette instead.
